# Security policy

This repository is a small practice project, but security reports are still welcome.

## Reporting a vulnerability

Do not include sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting or contact the maintainers privately through the repository profile.

Include:

- the affected file or behavior
- steps to reproduce
- the potential impact
- a suggested mitigation, if known

Please allow time for verification before publishing details. Never include real credentials, tokens, or personal data in an issue or pull request.
