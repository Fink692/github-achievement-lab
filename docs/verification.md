# Verification notes

Every change should leave a short record of how it was checked.

Use this format in a pull request:

- **Checks run:** commands, manual checks, or link review.
- **Result:** what passed or what was observed.
- **Scope:** what the check does not cover.
- **Follow-up:** any known next step.

For documentation-only changes, link review and a local render check may be enough. Do not claim a test was run when it was not.
