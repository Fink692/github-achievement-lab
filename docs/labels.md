# Labels

Use labels to make the work queue easier to scan.

Suggested labels:

- **bug:** behavior is incorrect
- **documentation:** text or examples need attention
- **feature:** a new capability is proposed
- **good first change:** intentionally small and well-scoped
- **blocked:** work depends on an external decision or change

Use one or two labels per issue. Prefer a clear title and body over a large collection of labels.
