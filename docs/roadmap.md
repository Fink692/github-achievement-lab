# Roadmap

The repository should stay useful as a collaboration practice space.

## Near term

- keep the contribution workflow easy to follow
- add examples only when they demonstrate a real GitHub feature
- keep checklists short and maintainable

## Later

- add a small automated link check
- document how to make a release
- invite a collaborator to review a change

Items are intentionally broad. Turn a roadmap item into a focused issue before implementing it.
