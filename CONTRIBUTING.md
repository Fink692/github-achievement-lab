# Contributing

Keep each contribution small enough to review in one sitting.

## Checklist

- Explain the problem in an issue.
- Use a branch named `feature/<short-description>` or `docs/<short-description>`.
- Link the pull request to the issue.
- Include a short testing or verification note.
- Keep commit messages specific and truthful.

## Quality bar

This repository is a practice space, not a commit counter. Do not create empty commits, duplicate issues, or meaningless pull requests. Every change should improve the project or document a useful workflow.
